gift_club - 동아리 추석선물 입금계좌 수집 시스템
====================================================

1. 서버 웹루트(www)에 gift_club 폴더 전체를 업로드합니다.
   private_config 폴더는 www의 상위 경로에 두는 것을 권장합니다.
2. 압축에 포함된 private_config/db_common.php 샘플에 실제 DB 정보를 입력합니다.
   - 기존 공통 DB 설정 파일이 이미 있다면 기존 파일을 그대로 사용하고 덮어쓰지 마세요.
3. 브라우저에서 /gift_club/install.php 접속 후 관리자 계정을 설정합니다.
4. 설치 완료 후 install.php는 삭제하거나 파일명을 변경하는 것을 권장합니다.
5. 관리자 로그인 후 [동아리설정]에서 동아리를 등록합니다.
6. 회원에게 /gift_club/ 주소를 안내합니다.

생성 테이블
- gift_clubs
- gift_submissions
- gift_admins
- gift_settings

재제출 규칙
- 동일한 '성명 + 숫자만 남긴 연락처'를 같은 회원으로 봅니다.
- 다시 제출하면 이전 행을 DELETE한 후 새 행을 INSERT합니다.
- 따라서 최종 제출내역 1건만 남습니다.

관리자 기능
- 대시보드
- 동아리 추가/수정/사용중지
- 제출내역 검색/동아리 필터
- Excel에서 바로 열 수 있는 UTF-8 BOM CSV 다운로드
- 회원화면 제목/안내문/제출마감 설정

보안 메모
- 계좌번호는 서버 DB에 평문 저장됩니다. 실제 입금업무에서 조회/엑셀 추출이 필요하기 때문입니다.
- 관리자 URL 및 계정을 외부에 노출하지 마세요.
- HTTPS 사용을 권장합니다.
- 수집목적 달성 후 제출 데이터와 내려받은 CSV 파일을 삭제하는 운영 절차를 두는 것을 권장합니다.
